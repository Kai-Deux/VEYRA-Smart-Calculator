
# VEYRA Smart Calculator

A Python command-line calculator developed by
VEYRA Digital Studio.

## Overview

VEYRA Smart Calculator is a modular Python application
designed to perform basic arithmetic operations with
input validation and automated unit testing.

## Features

- Addition, subtraction, multiplication and division
- Interactive command-line interface
- Input validation and error handling
- Division-by-zero protection
- Support for negative numbers and decimals
- Automated unit testing with unittest
- Clean, modular architecture

## Technologies

- Python 3.14
- Visual Studio Code
- Python unittest framework

## Project Structure

VEYRA-Smart-Calculator/
    main.py
    calculator.py
    validation.py
    tests/
        __init__.py
        test_calculator.py
    README.md

## Running the Application

Open main.py in VS Code and select Run Python File.

## Testing

Tests can be executed using the VS Code Testing panel.
